# ❄️SnowyAddons
- SnowyAddons is at is core a QOL mod for Hypixel Skyblock, including both legit QOL and soft-cheat modules, having untraceable features that give you an advantage.
- This is done by not interacting directly with the server, meaning that most "cheaty" modules on it only interact with client-side stuff, such as rendering (be ready to see a LOT of ESP modules in here lol).
> ⚠️***WARNING:* Please note that you are under the risk of getting banned EVEN with it being "untraceable" - *Use at your own risk.***
## Dependencies
- SnowyAddons directly depends on YACL for its config system. Its also recommended to use Mod Menu to easily access the settings menu through the "Mods" button implemented from Mod Menu!
